## 更新原则

1. 代码已实现但文档未说明时，先更新对应模块 README 和 API/业务契约。
2. 设计草案、课程材料和运行时事实要明确区分，不能用计划替代实现状态。
3. 数据库脚本变更必须同步迁移说明、初始化说明和影响范围。
4. 验收结论必须注明验证层级：源码、自动化测试、启动验证或真实浏览器链路。
